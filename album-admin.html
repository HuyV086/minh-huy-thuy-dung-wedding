Admin — Sắp xếp Album

← Xem trang album
Trang nội bộ, không gắn link công khai. Kéo ⠿ để đổi thứ tự, sửa chú thích, chọn ảnh bìa cho mỗi chương. Xong thì bấm Xuất media.json → thay file data/media.json trong repo → git add -A && git commit -m "..." && git push như quy trình đang dùng. Muốn thêm ảnh/video mới: thả file vào album-media/<chương>/ rồi chạy python3 scripts/build_album_manifest.py, sau đó quay lại đây sắp xếp tiếp.
